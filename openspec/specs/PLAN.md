# План разработки сайта DBSCAN Visual

Статус: День 1 и задача 1 Дня 2 выполнены; их описания ниже сохранены без изменений.

## День 1 — Подготовка проекта и каркас приложения
1. Инициализировать проект на Vite + React + TypeScript и настроить структуру по правилам: `src/app`, `src/pages`, `src/features`, `src/components`, `src/data`, `src/i18n`, `src/styles`, `src/hooks`.
2. Подготовить базовый роутинг с HashRouter и две страницы: Visualization и Theory; добавить корневой layout и базовый контейнер страницы.
3. Настроить CSS-переменные тем, глобальный фон с сеткой и минимальный UI shell: header, switcher, footer placeholder.

## День 2 — Базовый UI и темы/локализация
1. Реализовать страницу с двумерной компоновкой: Canvas panel + Steps panel, а также секцию с кодом и карточками сценариев по дизайну.
2. Добавить светлую и тёмную темы, хранение выбора в localStorage, и переключение языка ru/en с i18n-словарями для базовых текстов.
3. Сделать адаптивную сетку для mobile/tablet/desktop и подтвердить соответствие правилам из `openspec/specs/DESIGN.md`.

## День 3 — Ядро DBSCAN и подготовка сценариев
1. Создать чистый TypeScript-модуль для логики DBSCAN: точки, расстояние, соседство, рост кластера, шум, seeded PRNG, формирование кадров шагов.
2. Реализовать структуру данных шагов: состояния 0–9, рандомный выбор точки, рост кластера, подсчёт кластеров и шума.
3. Подготовить структуру сценариев: Circles, Blobs, Half-moons, Create; зафиксировать интерфейс данных и параметры `R`/`minPts`.

## День 4 — Canvas визуализация и интерактивность
1. Сделать Canvas-панель: сетка, зум, панорамирование, масштабирование по колесу/пинчу, корректный `devicePixelRatio`, отрисовку точек и окружности радиуса `R`.
2. Реализовать режим рисования/стирання для сценария Create: добавление/удаление точек, ограничение в 1024, всплывающее уведомление об ошибке.
3. Подключить пересчёт и сброс состояния при изменении `R`, `minPts`, сценария или набора точек.

## День 5 — Шаги, анимации и состояние алгоритма
1. Реализовать панель шагов: Start/Next, список шагов 0–9, переход по предыдущим шагам, автопрокрутка и активный шаг.
2. Добавить анимации переходов между шагами: изменение цветов точек, движение окружности `R`, плавные появления новых элементов и развёртывание текста описания.
3. Подвязать сценарный запуск: шаги запускаются только после нажатия Start, и состояние воспроизводится по seed.

## День 6 — Код, теория и финальные блоки
1. Реализовать блок с кодом на Python/JavaScript/C++, табы, syntax highlighting и копирование.
2. [x] Сделать “Theory” страницу с простым контентом по DBSCAN, адаптированным под новичков, с плавным появлением блоков на scroll.
3. Добавить footer note и все текстовые ссылки/placeholder-элементы в соответствии со спецификацией.
4. [x] Оптимизировать и исправить недочёты в примерах DBSCAN на Python, JavaScript и C++ (например, использовать `math.dist()` в Python вместо самодельной функции расстояния).
